# System Design Notes

```
system-design/
  hld/
    HLD-System-Design-Roadmap.md   <- checklist, start here
    concepts/    one note per topic
    designs/     one note per practice problem
    diagrams/
  lld/
    concepts/    SOLID, design patterns, concurrency
    designs/     parking lot, vending machine, ...
    diagrams/
  templates/     copy these to start a new note
  mistakes-and-gaps.md
```

New to this? Read [[hld-vs-lld]] first (what HLD and LLD are).

## How to start a new note
1. Copy `templates/concept-template.md` or `templates/design-template.md` into the right folder.
2. Rename it in lowercase with hyphens, e.g. `consistent-hashing.md`.
3. Write in your own words. Keep it to about a page.
4. Log anything you got wrong in `mistakes-and-gaps.md`.

## Where to begin
Open `hld/HLD-System-Design-Roadmap.md` and start at Stage 1.
